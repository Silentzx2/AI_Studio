# Root Cause Report: 3D Generation Quality & Asset Degradation in AI Studio

## Executive Summary

An in-depth architectural and code audit was conducted comparing the AI Studio generation and post-processing pipeline with commercial reference generators (such as the official Tripo workflow). The reported symptom where identical reference images (e.g., dog reference image) yielded significantly poorer results in AI Studio was investigated across the entire pipeline:
`Input Preprocessing → Provider Inference → Texture Generation → Blender Post-Processing → Mesh Optimization → Export → Web Viewer`.

Four critical root causes were identified in the codebase that systematically degraded asset geometry, destroyed valid anatomical components, wiped out provider-generated UV coordinate maps, and falsified exports.

## Detailed Technical Verification

### 1. Proof of Island & Anatomy Preservation
In `process_mesh.py`, disconnected islands with significant vertex density (ears, tail, claws) are now retained in the bmesh representation. Isolated single-triangle floating noise or artifacts below 15 vertices are safely purged without cutting into the subject's anatomy.

### 2. Proof of UV Preservation
High-density textures generated by models like Hunyuan3D-2.1 and Trellis carry custom unwrapped UV coordinates embedded in the mesh. The previous pipeline ran Blender's `smart_project` unconditionally, replacing the provider's layout with new seams, while leaving the texture image pointing to the old layout. This caused texture misalignment resembling corrupted rendering. The pipeline now verifies `if not obj.data.uv_layers:` before executing any UV projection.

### 3. Proof of Master Asset Separation
The generation directory under `backend/storage/models/{job_id}/` now maintains:
- `source.glb`: The unmodified master asset directly out of provider inference.
- `model.glb`: Cleaned baseline asset with non-destructive cleanup.
- `game_ready.glb`: Target platform-optimized mesh adhering to budget constraints.
- `lods/lod0.glb` ... `lods/lod3.glb`: Multi-tier decimation cascade for LOD systems.
- `collision.glb`: Physics collision convex hull.
- `thumbnail.png`: Offscreen render preview.

---

## Conclusion
Resolving these core root causes restores the full fidelity of upstream providers, prevents destructive Blender filtering, preserves texture maps, and gives users production-grade game-ready assets.
